# Mostruário — Cantinho Pizza Burguer

Protótipo visual inspirado na experiência de apps modernos de delivery, sem copiar identidade visual proprietária.

Arquivos:
- index.html
- style.css
- script.js

Recursos demonstrativos:
- Cabeçalho estilo app de delivery
- Busca
- Categorias
- Banner/promos
- Cards de produtos
- Carrinho lateral
- Checkout em modal
- Barra inferior mobile
- Visual responsivo

Este projeto é apenas mostruário. Não possui Supabase, estoque real nem envio de pedido.
